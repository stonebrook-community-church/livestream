# Setup Checklist

Times are targets. "T-30" means 30 minutes before the service starts. Logins are on the private booth card.

## Before the service

**T-60 — Arrive**

- [ ] Arrive at the booth.
- [ ] Turn on the booth computer, Stream Deck and SuperJoy if they are off.
- [ ] Open Ecamm Live.

**T-55 — Cameras** ([Preset Map](preset-map.md))

- [ ] Recall **P1–P4 on Cam 1**. Each one matches the Preset Map.
- [ ] Recall **P1–P5 on Cam 2**. Each one matches the Preset Map.
- [ ] Brightness and color look the same on every preset. Exposure stays manual (values: TBD).

**T-45 — Scenes** ([Stream Deck](stream-deck.md))

- [ ] Press each Stream Deck button **1–9**. Each scene matches the Stream Deck sheet.
- [ ] Ask the ProPresenter operator to show a lyric and a slide. Check both appear in Ecamm.
- [ ] Lyrics sit in the lower third, not full screen.

**T-35 — Go to Countdown**

- [ ] Press **Countdown (1)**.
- [ ] Start broadcasting in Ecamm.
- [ ] Pre-position **Cam 1 P2** and **Cam 2 P2** for the first song.

**Before T-30 — Countdown is live**

- [ ] Ecamm is broadcasting **Countdown (1)**. Resi auto-starts at T-30.

## End of service

- [ ] After the benediction, press **End Slate (9)**.
- [ ] Leave End Slate on air. Don't rely on Resi's 1-hour auto-end. It is only a fallback for special events.
- [ ] **Service end +5 min: manually end Resi stream.** Only after that, stop broadcasting in Ecamm.
