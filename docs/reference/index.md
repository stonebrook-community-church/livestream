# Booth Reference

One-page sheets to print and keep at the booth. For the "why" behind each step, read the [Onboarding guide](../onboarding/index.md).

| Sheet | Use it |
|---|---|
| [Setup Checklist](setup-checklist.md) | From T-60 until Countdown is live, and at the end of the service |
| [Run Sheet](run-sheet.md) | During the service, segment by segment |
| [Preset Map](preset-map.md) | What each camera preset shows |
| [Stream Deck](stream-deck.md) | What each button does |

To print a sheet, open it and press Ctrl+P (Cmd+P on a Mac). Each sheet fits on one Letter page.
