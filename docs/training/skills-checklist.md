# Skills Checklist

For the Livestream Lead, at the last step of the [Onboarding Path](../onboarding/index.md). Tick a skill only after the volunteer does it at the booth without help.

<div class="skills-checklist" markdown>

## Setup

| Skill ([Setup Checklist](../reference/setup-checklist.md)) | Done | Date |
|---|:-:|---|
| Turn on the booth computer, Stream Deck and SuperJoy, and open Ecamm Live. | <input type="checkbox" aria-label="Done: Turn on the booth computer, Stream Deck and SuperJoy, and open Ecamm Live"> | |
| Recall every preset on both cameras and compare each one to the Preset Map. | <input type="checkbox" aria-label="Done: Recall every preset on both cameras and compare each one to the Preset Map"> | |
| Check scenes 1–9 in the preview against the Stream Deck sheet, without publishing. | <input type="checkbox" aria-label="Done: Check scenes 1–9 in the preview against the Stream Deck sheet, without publishing"> | |
| With the ProPresenter operator, check a lyric and a slide both show in Ecamm. | <input type="checkbox" aria-label="Done: With the ProPresenter operator, check a lyric and a slide both show in Ecamm"> | |
| Publish Countdown (1) and start broadcasting in Ecamm before T-30. | <input type="checkbox" aria-label="Done: Publish Countdown (1) and start broadcasting in Ecamm before T-30"> | |

## Switching

| Skill ([Scenes](../onboarding/scenes.md)) | Done | Date |
|---|:-:|---|
| Say which camera is live and which is off-air, at any moment. | <input type="checkbox" aria-label="Done: Say which camera is live and which is off-air, at any moment"> | |
| Load a scene with its button, check the preview, then press Publish. | <input type="checkbox" aria-label="Done: Load a scene with its button, check the preview, then press Publish"> | |
| Switch songs between Cam 1 + Lyrics (2) and Cam 2 + Lyrics (3). | <input type="checkbox" aria-label="Done: Switch songs between Cam 1 + Lyrics (2) and Cam 2 + Lyrics (3)"> | |
| Announcements: Cam 1 Clean (4), and Full Slide (6) only when slides are shown. | <input type="checkbox" aria-label="Done: Announcements: Cam 1 Clean (4), and Full Slide (6) only when slides are shown"> | |
| Sunday school dismissal: Cam 1 Clean (4) on Cam 1 P2. No slides. | <input type="checkbox" aria-label="Done: Sunday school dismissal: Cam 1 Clean (4) on Cam 1 P2. No slides"> | |
| Break (8) for the 5-minute break, then back for the sermon. | <input type="checkbox" aria-label="Done: Break (8) for the 5-minute break, then back for the sermon"> | |
| Sermon: switch between Cam 1 Clean (4) and Sermon Split (7). | <input type="checkbox" aria-label="Done: Sermon: switch between Cam 1 Clean (4) and Sermon Split (7)"> | |
| Communion: Cam 2 Clean (5) on Cam 2 P4. | <input type="checkbox" aria-label="Done: Communion: Cam 2 Clean (5) on Cam 2 P4"> | |

## Presets
